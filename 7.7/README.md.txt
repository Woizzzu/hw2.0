# Book Catalog (C++17)

Консольное приложение для управления каталогом книг с использованием контейнера `std::vector`, классов и стандартных алгоритмов STL (`std::sort`, `std::count_if`, `std::string::find`).

## Требования
- Компилятор с поддержкой стандарта **C++17** (GCC 7+, Clang 5+, MSVC 2017+).

## Компиляция и запуск

### Linux / macOS (GCC / Clang)
```bash
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o catalog
./catalog
```

### Windows (MinGW / GCC)
```bash
g++ -std=c++17 -Wall -Wextra -O2 main.cpp -o catalog.exe
catalog.exe
```

### Windows (MSVC)
```bash
cl /std:c++17 /EHsc main.cpp
main.exe
```

## Команды меню

| Команда | Действие |
| :---: | :--- |
| `1` | Добавить новую книгу (название и год издания) |
| `2` | Показать все книги в каталоге с порядковым номером |
| `3` | Сортировать книги по году издания (по возрастанию) |
| `4` | Сортировать книги по году издания (по убыванию) |
| `5` | Найти все книги по части названия |
| `6` | Подсчитать количество книг, изданных строго после заданного года `Y` |
| `0` | Выход из программы |
